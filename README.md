A project built for CSE-4746	Numerical Methods Lab.
Features:
Euler's Method: First-order explicit single-step method for basic numerical approximation.

Heun's Method (Improved Euler): Second-order predictor-corrector approach improving stability and convergence.

Runge-Kutta 4th Order (RK4): Fourth-order standard method delivering high accuracy across non-stiff systems.

Error Analysis: Comparative evaluation showing absolute errors against analytical (exact) solutions.

Tabular & Graphical Output: Clean console logging alongside trajectory plots comparing method convergence.
